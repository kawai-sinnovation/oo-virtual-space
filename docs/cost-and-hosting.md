# oO Virtual SPACE — 公開・費用の目安（GitHub 前提）

この資料は、ホスティングを **GitHub（リポジトリ + GitHub Pages）** にした場合に、「当面ここまでは無料でできる」範囲と、その先で月額が発生しうる条件をまとめたものです。

見本（いま公開中）: [https://kawai-sinnovation.github.io/oo-virtual-space/](https://kawai-sinnovation.github.io/oo-virtual-space/)  
ソース: [https://github.com/kawai-sinnovation/oo-virtual-space](https://github.com/kawai-sinnovation/oo-virtual-space)

---

## 結論（資料に載せる一文）

**見本の公開は GitHub Pages（無料）。試作・少人数の実験までは月額 0 円で始められる。本営業・常時稼働・無料枠の超過・商用配信などでは月額が発生しうる。**

※本番運用まで「ずっと月額 0 円」とは書いていません。

---

## 当面ここまでは無料でできること

| できること | 使うもの | 費用感 |
|------------|----------|--------|
| 見本・プロトタイプの公開 | GitHub Pages | **無料** |
| ソースの保管・共有 | GitHub 公開リポジトリ | **無料** |
| ブラウザだけで動く 2D モックの閲覧・操作デモ | 静的フロント（本リポ） | **月額 0 円** |
| 少人数での試作・社内確認・関係者へのリンク共有 | 同上 | **月額 0 円で開始可** |

いまのモックは Discord SDK や Supabase に接続せず、ブラウザ単体で動きます。そのため **見本公開と試作段階ではサーバー代がかかりません。**

### 試作は月額 0 円で始められる理由

1. **見本は GitHub Pages** に静的サイトとして置く（追加の有料ホスティング不要）
2. フロントの試作・操作確認はローカルまたは Pages 上で完結する
3. 在席・チャット・AI などの有料 API をまだ使っていない

---

## 月額が発生しうるタイミング（本番を「完全無料」にしない）

次に進むと、無料枠を超えた分や有料プランが必要になることがあります。

| 進み方の例 | 想定されるコスト要因 |
|------------|----------------------|
| 本営業・常時オープンな空間として運用 | 在席・認証・DB・音声/動画などの常時稼働サービス |
| 同時接続や保存量が増える | クラウド／BaaS の無料枠超過 |
| 商用配信・有料イベント・大規模告知 | 配信・帯域・サポート・ライセンス |
| AI 応答（例: Gemini）を常時・多人数で使う | API 従量課金（少人数の試作なら無料枠内に収まることもある） |
| Discord 連携やリアルタイム同期を本番化する | 連携基盤・監視・運用の費用 |

おおよそ **30 人規模の少人数実験**であれば、各サービスの無料枠内で試せる余地はありますが、**本営業・常時稼働を「月額 0 円」と約束するものではありません。**

## 推奨アーキテクチャ（段階的）

```text
【いま／試作】
  GitHub リポジトリ → GitHub Pages（静的モック）
  費用: 月額 0 円

【次の実験】
  同上 + 必要なら無料枠の BaaS / AI API を試験接続
  費用: 枠内なら 0 円、超過・有料機能で発生

【本営業】
  常時稼働・認証・リアルタイム・商用要件に応じた有料プラン
  費用: 月額が発生しうる（要件ヒアリング後に見積もり）
```
